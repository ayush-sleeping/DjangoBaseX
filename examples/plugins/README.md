# Example plugins

Reference plugins that are **never loaded** by the boilerplate. CI installs them to prove the
plugin seam on every push. `notes/` is the minimal reference to copy; `enquiries/` is the second
product (BUILD_ORDER 10.1), using numbering, a state machine and money. See `notes/README.md` to try one locally, and
`documentation/planning/CORE_ARCHITECTURE_PLAN.md` § 1–§ 6 for the contract they follow.
