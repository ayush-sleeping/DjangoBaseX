# Editing documentation — read before editing

This file holds no rules (ADR-0006, ADR-0007). It tells you where they are.

- `documentation/INDEX.md` § "What belongs in which folder": which folder a doc goes in. Add a row when you add
  a doc.
- `AGENTS.md` § 1 rules 5 and 5a: this repository is public, and no other codebase is ever named.
- `AGENTS.md` § 4: the "recorded in" table, which says what each kind of change updates.
- `documentation/ADR.md`: Accepted records are settled, and changing one takes a new ADR. The `/adr` skill covers
  the procedure.
- `documentation/DAILY_CHANGES.md` § Format: the entry template. The `/changelog` skill covers the procedure.
